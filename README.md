# 🚀 PathCrafter

**PathCrafter** — це науково-фантастична 3D гра-головоломка на рушії **Godot 4 (.NET / C#)**, у якій гравець керує марсоходом за допомогою реального коду мовою **C++**, прокладаючи безпечні маршрути через небезпечні ландшафти Марса.

---

## 📸 Галерея та Дизайн

- **Меню вибору місій**: Стилізоване під тактичні схеми друкованих плат марсохода (Глава 1 — світла друкована плата, Глава 2 — темний сектор).
- **Секторний редактор рівнів**: Промисловий інтерфейс Mission Control із повною підтримкою розміщення об'єктів та орієнтації 3D-моделі ровера.
- **Вбудована консоль інженера (IDE)**: Тема One Dark C++, автодужки, інтелектуальне автодоповнення (IntelliSense) через `Tab` / `Enter`.

---

## 🎮 Ключові можливості

### 1. 🤖 Симуляція ровера та сітка (Grid Gameplay)
- Дискретна навігація по плитковій сітці ($X, Z$).
- Повна взаємодія з перешкодами: каміння (блокування шляху), ями (падіння ровера з плавною анімацією), фінішний модуль.
- Збереження початкового положення та орієнтації ровера ($0^\circ, 90^\circ, 180^\circ, 270^\circ$).

### 2. 💻 Вбудований редактор коду C++ (Tactical IDE)
- **Синтаксис C++**: 
  ```cpp
  #include <moving>

  int main() {
      rover.move();
      rover.turn_left();
      rover.move();
      return 0;
  }
  ```
- **Парсер та інтерпретатор** (`CodeParser.cs`, `Command.cs`): перевірка синтаксису вхідних команд, робота з циклами `for`, перевірка точок з комою та імені ровера.
- **IntelliSense & автодоповнення**:
  - Автоматичне закриття парних символів: `{ }`, `( )`, `[ ]`, `< >`, `" "`.
  - Розумні підказки при введенні префіксів `rover.`, `#include`, `for`, `main`.
  - Підтвердження підказки клавішами `Tab` або `Enter`.
- **Автозбереження**: Код гравця для кожного рівня автоматично зберігається на диск і відновлюється при повторному відкритті рівня.

### 3. 🗺️ Вибір рівнів у стилі друкованих плат (Circuit Boards)
- **Глава 1** та **Глава 2**: Динамічне перемикання між світлою та темною схемою плат за допомогою навігаційних стрілок `<` та `>`.
- **Вільне позиціонування кнопок рівнів** (`LevelNodes`): 8 кнопок місій для кожної глави, які розташовуються точно вздовж струмопровідних доріжок.
- **Система прогресу**: Відстеження пройдених місій (`Global.UnlockedLevelIndex`) та розблокування наступних рівнів.

### 4. 🛠️ Секторний редактор рівнів (Level Editor)
- Швидка генерація робочої сітки довільного розміру ($N \times M$).
- Встановлення елементів правою/лівою кнопкою миші: `⛰ Камінь`, `🕳 Яма`, `🎯 Фініш`, `🤖 Точка спавну ровера`.
- **Справжня 3D модель марсохода** у редакторі з неоновим покажчиком напрямку.
- **Орієнтація ровера**: Кнопка повороту та гаряча клавіша `[ R ]` для миттєвого циклічного повороту на $90^\circ$ ($0^\circ, 90^\circ, 180^\circ, 270^\circ$).
- Збереження рівнів у форматі Godot сцен (`res://scenes/levels/customs/Level_X.tscn`).

### 5. 🎵 Аудіо та система збереження
- Фонова музика меню, вибору місії та геймплею (`Audio.cs`).
- Звуки руху гусениць ровера, падіння в яму, зіткнення, кліків та перемоги.
- Автоматичне збереження у конфігураційний файл `user://save_game.cfg`.

## 🛠️ Встановлення та запуск

### Вимоги
- **Godot Engine 4.3+ або 4.7+ (з підтримкою .NET / C#)**
- **.NET SDK 8.0+**

### Збірка проекту
У корені проекту виконайте:
```bash
dotnet build
```

### Запуск через Godot
1. Відкрийте Godot Engine.
2. Імпортуйте проект, вказавши файл `project.godot`.
3. Натисніть **F5** або кнопку **Play** для запуску гри.

---

## 📐 Як налаштувати кнопки рівнів на платі в редакторі
1. Відкрийте сцену `res://scenes/ui/LevelSelectMenu.tscn` у редакторі Godot.
2. У дереві сцени виберіть вузол `LevelNodes`.
3. У 2D-в'юпорті ви побачите кнопки `Btn_Level_1` ... `Btn_Level_8`, розміщені поверх схеми друкованої плати.
4. Мишкою перетягніть кожну кнопку на потрібне перехрестя ліній, якщо бажаєте змінити їхні позиції.
5. Збережіть сцену (`Ctrl + S`).
